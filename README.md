# ひらめきの本棚

`index.html`を開くと遊べます。インストール・外部フォント・通信は不要です。静的ホスティングには、このフォルダの内容を配置してください。`_headers`に対応するホストでは同梱のセキュリティ設定が適用されます。

同じ本を上下左右に3つ以上つなぐと、置いた場所に1段階上の本が生まれます。斜めは対象外。成長した本がさらに3つつながると連鎖します。レベル8は最終形です。

- ふだんの本棚：手数無制限。開始ごとに本の順番が変わります。
- 今日の本棚：日本時間の日付ごとに共通の配置・順番、50手。開始日を固定します。今日の成績は自己ベストです。
- 保留：1回置くまでに1回、現在の本とストックを交換。最初は現在の本を預けます。
- 整理：2回まで、好きな本を1つ除去。満杯でも整理が残っていれば使えます。
- 1手戻す：直前の配置・保留・整理を1操作だけ戻します。図鑑と自己ベストは戻りません。

空きマスを選んで配置します。キーボードではTabで各操作、盤面上は矢印キーで移動、EnterまたはSpaceで決定。空きマスにフォーカスすると合成の予告が表示されます。

自己ベストと図鑑はブラウザ内のlocalStorageだけに保存します。進行中の盤面は保存しません。保存不可でも遊べます。記録の削除は画面下から行えます。共有文章にURLや端末情報は含みません。外部リンクは結果画面の「まなびの扉」のみです。

本や盤面の描画はコードで作成したSVG、背景には生成したオリジナル画像を使用しています。音声はありません。`thumbnail.svg`は文字なしの設置用画像です。

エンジンは`engine.js`。ブラウザの`BookshelfEngine`とCommonJSの両方から利用できます。`create`、`place`、`hold`、`remove`、`undo`は状態を引数・戻り値にするAPIです。無効操作は元の状態を返します。`connected`で上下左右の群、`supply`でseedごとの順番を検証できます。
